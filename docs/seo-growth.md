# SEO growth plan

## Current objective

Earn MyToolMint's first genuine organic visitor, then grow measured search traffic without publishing thin or duplicated pages.

## Word-tool keyword map

| Canonical page | Primary intent | Supporting intent | Page distinction |
| --- | --- | --- | --- |
| `/word-unscrambler/` | word unscrambler | unscramble words, unscramble letters, words from letters, word descrambler, free word unscrambler | Finds every valid shorter word from a supplied letter rack, with length and pattern filters. |

## Decisions

- Treat Bing and Google Keyword Planner volumes as directional demand signals, not traffic forecasts.
- Keep close variants with the same user intent on one strong canonical page.
- Do not index arbitrary search or filter combinations. Interactive state uses URL fragments, which are not separate crawlable documents, while each page keeps a clean canonical URL.
- Avoid trademarked game names in branding and metadata. Generic word-game explanations are sufficient.
- Do not buy backlinks, publish automatically generated word pages or create cloned keyword landing pages.
- Google Ads competition describes advertiser activity, not organic ranking difficulty.

## Weekly review

Review Google Search Console and Bing Webmaster Tools for:

1. Clicks, impressions, click-through rate and average position.
2. New queries and the page receiving each query.
3. Indexing, sitemap, crawl and canonical issues.
4. Queries with impressions but weak click-through rates.
5. Pages ranking between positions 8 and 25 that may benefit from a useful content or internal-link improvement.

Make changes only when the data or a clear user need supports them. Record material changes in the roadmap and allow enough time for search engines to recrawl before judging the result.
